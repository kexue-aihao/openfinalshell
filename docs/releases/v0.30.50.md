# OpenFinalShell v0.30.50

- 修复 `0.30.49` 命令编辑器拖动无效的问题。
- 将标题栏移入对话框内容区，避免 `ContentDialog` 模板标题对指针事件和布局的限制。
- 拖动改为使用 WinUI 合成层 `Translation` 移动整个对话框，不再依赖 `RenderTransform`。
- 拖动范围继续限制在当前应用可视窗口内，宽屏、竖屏和紧凑窗口均适用。

## 验证

本地核心契约、拖动边界测试、桌面测试、TypeScript、i18n、Electron 构建、bundle 预算和 WinUI3 x64/x86/ARM64 构建通过；正式安装包与发布产物由 GitHub Actions 发版流水线验证。
