# OpenFinalShell v0.30.76

- 局域网同步协议新增 Rust 原生实现（napi-rs）。首个切片只接管 `lansync` 的纯编解码：UDP 发现报文、TCP 帧编解码与增量拆帧器，零 I/O、零状态机迁移。
- 原生模块是**可选增强**：`.node` 缺失、加载失败或被熔断时整个模块回退到原 TypeScript 实现，行为逐字节一致（58 条金标 + 10,000 例随机帧差分验证）。
- 新增三态开关：`OFS_CORE_BACKEND=ts|rust|auto`（默认 `auto`）、`OFS_RUST_MODULES`（默认 `lansync`）、`OFS_NATIVE_DISABLE=1` 全局熔断；`rust` 模式下缺件会直接启动失败，供 CI 校验使用。
- 原生产物走 `extraResources` 放进 `resources/ofs-native/`，不进 asar、不进 npm 依赖树，不会被 `install-app-deps` / electron-rebuild 重编。
- 新增 Rust 流水线（9 个目标架构的 `cargo fmt`/`clippy`/`test` 与 `.node` 构建）以及 Linux / macOS 打包流水线；Linux 与 macOS 首版不打包 FreeRDP worker，嵌入式 RDP 报 `WORKER_MISSING`。
- 本版同时修复了 v0.30.75 发版时的两处流水线问题：原生模块改为平铺暂存，使打包后的 `resources/ofs-native/ofs_napi.node` 与运行时加载路径一致；应用内更新说明补齐到当前版本（WinUI 侧的原生契约测试会校验这条）。

验证：`npm run typecheck`、`check:i18n`、`build`、`check:bundle` 通过；Rust 侧 `fmt`/`clippy -D warnings`/`cargo test` 26 项全绿；Electron 测试在 `OFS_CORE_BACKEND=ts` 下 1788 通过、`rust` 下 1790 通过（37 跳过）；WinUI 原生契约 416 项通过；`ofs_napi.node` 611,840 字节并通过架构与自检校验。
