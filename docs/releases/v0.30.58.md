# OpenFinalShell v0.30.58

- 优化 WinUI 3 原生版启动与关闭流程：数据库完整性校验在后台执行，并显示轻量启动界面；第二实例聚焦改为异步；窗口关闭时完整释放编辑器、RDP、会话、传输与实例协调资源。
- 提升原生终端吞吐与检索响应：新增 `ofs-terminal` 批量屏幕/回滚区快照接口，终端输出按时间片让出 UI 线程，搜索支持防抖、分批扫描和取消，搜索结果高亮不再按单元格遍历全部匹配。
- 减少 UI 事件风暴：批量传输更新合并、SFTP 大目录单次集合刷新、AI 流式响应节流、RDP 帧与鼠标移动合并；非当前会话的终端输出采用背压延迟。
- 修复语言切换时重复订阅 LAN Sync 的功能性缺陷，并移除窗口、分栏拖动和 Scintilla 布局热路径中的重复数据库与窗口查询。
- 为覆盖层、连接抽屉、侧栏、工具条和拖放反馈加入克制的 WinUI Composition 动效，同时遵循系统的减少动画与高对比度设置。

WinUI 3 x64、x86、ARM64 构建均为 0 警告、0 错误；Native Core 契约测试 409 项、Native SSH 契约测试 49 项通过；`ofs-terminal` x64/x86 probe 通过，ARM64 交叉编译通过；隔离数据启动、关闭清理和终端布局 fixture 冒烟通过。完整 DPI、主题、高对比度及长时间压力矩阵仍由发布流水线和后续真机验收覆盖。
