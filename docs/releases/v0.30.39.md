# OpenFinalShell v0.30.39

- 修复 WinUI3 SSH 终端输入客户端无法获得实际键盘焦点，以及普通字符被 TextBox 截留的问题。保留原 SSH 连接、传输和终端解析业务。
- SFTP 修改时间明确显示为 `2026/11/7周六 上午 09:25:30`，增加日期列宽和列间距。
- 更新确认后复用未保存文件确认流程，安装器验证和权限确认成功后自动退出应用，关闭 RDP 工作进程，更新完成后由原用户进程重新启动。取消权限确认不关闭会话。
- 引入 RSA 签名文件清单、SHA-256 文件校验和 HTTP 范围下载；不变文件从本地复用，仅下载变化文件的 gzip 数据。替换失败时恢复备份，不删除未知用户文件。服务器不支持范围请求时明确失败，不静默改为整包下载。
- 首次启动和升级后的首次启动均显示可滚动的历史更新说明，按窗口大小限制弹窗，当前版本在最上方。

## 升级说明

`v0.30.38` 及更早的原生客户端没有新增量更新器，需要一次完整覆盖升级到本版。旧客户端若仍要求手动关闭会话，请保存工作、退出程序，再运行本版安装器。连接与凭据数据保留，默认安装目录仍为 `C:\Program Files\OpenFinalShell Native Preview`。

从本版更新到后续支持该清单的版本，内置更新只下载变化文件，不重新下载安装整个程序。首次安装仍使用完整安装器；跨版本升级通过逐文件校验确定差异。

## Validation

Native compilation and contract tests, TypeScript checks, i18n checks, unit tests, signed payload generation, range-download verification, rollback on locked files, and an isolated updater process shutdown/apply/restart test are included in this change. SSH input is checked against the local SSH fixture; live production host credentials are not used.
