# OpenFinalShell v0.30.74

- 新增 Ctrl/Cmd+K 快速切换器：Electron 与 WinUI 均可按名称即时过滤已打开标签和已保存连接，回车直接跳转，Esc 关闭并恢复焦点。
- 优化渲染与重绘开销：监控图表改用挂载期 ResizeObserver 与 rAF 合流，采样更新改为不可变副本；连接树搜索加入 140ms 防抖并预建父子索引；布局拖拽写盘合并为 180ms 一次。
- 统一动画流转：WinUI 侧新增内容切换、侧栏与浮层过渡，并缓存系统动画/高对比度设置、用版本号避免快速开关错乱；Electron 侧为侧栏、监控面板、活动栏与会话视图补充入场动画。
- Android 页面切换加入淡入淡出并保留滚动位置与表单草稿，连接列表改为映射查找，SFTP 传输列表限制渲染条数。

验证：`npm run typecheck` 与 `npm run check:i18n` 通过；Electron 测试 1788 通过、37 跳过；Android 因本机未配置 SDK 未编译，由 CI 构建验证。
