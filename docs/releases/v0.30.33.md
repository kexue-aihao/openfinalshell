## 0.30.33 更新内容

本次发布加入 WinUI 3 原生预览版，并为原生版接入签名自动更新器。

- **原生自动更新。** Windows 原生版会检查架构专属 GitHub Release feed，下载后验证 RSA 清单签名、架构、文件大小和 SHA-256，再启动安装器。
- **安全覆盖升级。** 用户确认后，安装器以静默模式启动，并等待旧进程退出后再覆盖文件；安装结束后自动重启新版。存在 SSH 会话、传输、活动转发、未保存编辑器或 RDP 会话时不会安装。
- **数据保留。** 安装目录与 `%LOCALAPPDATA%\OpenFinalShell.NativePreview` 数据目录分离。覆盖安装和卸载不会删除连接、凭据、known hosts、分组或转发规则。
- **原生构建产物。** Release 同时提供 x64、x86 和 ARM64 自包含安装包及对应 `native-update-*.json` 签名清单。原生安装包作为预览版提供，Electron 客户端仍是正式 Windows 客户端。
- **本机验收。** Windows 11 x64 已完成 0.30.32 到 0.30.33 的签名 feed 自动下载、静默覆盖安装、重启、升级后 feed 检查和数据库保留验证。

### 已知边界

- x86 和 ARM64 已完成交叉构建与签名，尚未在对应真机启动验收。
- NSIS 安装器尚未使用 Authenticode 发布者证书签名；更新内容由 RSA 清单和 SHA-256 校验。
- 自动回滚、真实 Linux 监控主机、RDP 服务及 Android 互操作仍未在本轮验收。

### English

This release adds the WinUI 3 native preview and a signed automatic updater for the native client.

- The native client checks an architecture-specific GitHub Release feed and verifies the RSA-signed manifest, architecture, package size and SHA-256 before installation.
- After in-app confirmation, the installer runs silently, waits for the old process to exit, replaces the application and restarts it. Active SSH sessions, transfers, forwards, unsaved editors and RDP sessions block installation.
- Application data remains in `%LOCALAPPDATA%\OpenFinalShell.NativePreview`, separate from the install directory. Upgrade and uninstall preserve connections, credentials, known hosts, groups and forwarding rules.
- The Release includes self-contained x64, x86 and ARM64 native installers plus signed `native-update-*.json` feeds. The native client remains a preview; Electron remains the production Windows client.
- Local Windows 11 x64 acceptance completed a signed 0.30.32 to 0.30.33 download, silent in-place upgrade, restart, post-upgrade feed check and data-retention verification.

Known limits: x86 and ARM64 have cross-build and signature coverage but no matching-device runtime acceptance; the NSIS installer is not Authenticode-signed; automatic rollback and real Linux, RDP and Android interoperability remain outside this validation.
