# OpenFinalShell v0.30.41

- 优化 WinUI3 原生编辑器窗口的应用标识、标题栏与主题边框；设置页现在直接展示分组快捷键。
- 重整原生服务器监控面板的信息层级、磁盘用量、趋势图例和状态反馈。
- SSH 连接阶段显示目标与被动加载进度；连接成功后按连接配置自动打开监控侧栏。
- 为原生连接编辑器与连接树增加离线国家/地区、局域网和公网位置标记，继续使用已有 `flag` 字段。
- 改动仅涉及 WinUI3 前端呈现、本地化文案和离线地区资源，不修改 SSH、监控采集、远程保存或配置协议。
