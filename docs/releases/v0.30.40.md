# OpenFinalShell v0.30.40

- 修复 WinUI3 原生终端普通单击后遗留一个选中色块的问题。单击仅定位输入焦点，只有拖选才产生选区。
- 隐藏文本输入客户端自身的光标和焦点装饰，保留正常闪烁的终端光标；输入法组字时显示输入法编辑区域。
- 修复拖选完成后自动复制文字的行为，支持单字符选区，并保留「选中即复制」设置（默认开启）。继续输入或单击时清除旧选区。
- 改动仅涉及原生终端前端，不修改 SSH/SFTP、远程保存或编码业务。

## 升级

原生版 v0.30.39 可通过内置更新器增量升级，仅下载变化文件。v0.30.38 及更早版本需一次完整覆盖安装，才能获得增量更新器。默认安装目录仍为 `C:\Program Files\OpenFinalShell Native Preview`。

## 验证

x64 WinUI3 构建通过，0 警告、0 错误。使用隔离的本地 SSH 测试服务，实测单击无残留色块、530ms 光标明暗切换、文字输入回显，以及不按 Ctrl+C 的拖选复制和单字符复制。未使用生产主机进行测试。
