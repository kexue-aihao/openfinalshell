# OpenFinalShell v0.30.36

- **原生安装器界面同步 Electron。** WinUI 3 NativePreview 安装器改用同样的 MUI2 向导式流程，保留自定义安装目录、图标和完成后启动选项。
- **修复原生卸载。** 原生版现在注册到当前用户的 Windows 卸载列表，卸载前会关闭运行中的进程，删除快捷方式、注册表项和完整安装目录；连接、凭据及 `OpenFinalShell.NativePreview` 数据目录仍保留。

- **Native installer matches Electron.** The WinUI 3 NativePreview installer now uses the same assisted MUI2 wizard flow, with a custom installation directory, matching icon and a launch-after-finish option.
- **Native uninstall is complete.** The native app is registered in the per-user Windows uninstall list, stops running instances before removal, and deletes shortcuts, registry entries and the complete installation directory while preserving the `OpenFinalShell.NativePreview` data directory.
