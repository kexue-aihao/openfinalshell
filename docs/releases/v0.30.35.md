## 0.30.35 更新内容

- **统一原生版图标。** WinUI 3 原生版现在使用与 Electron 相同的 OpenFinalShell 渐变终端图标，覆盖程序文件、窗口标题栏、任务栏以及原生安装器和卸载器。
- **图标尺寸。** 原生 ICO 包含从 16 到 256 像素的多尺寸透明图像，适配不同 Windows 显示比例和资源管理器视图。

### English

## 0.30.35 release notes

- **Unified native app icon.** The WinUI 3 preview now uses the same OpenFinalShell gradient terminal icon as Electron for the executable, window title bar, taskbar, installer and uninstaller.
- The native ICO includes transparent sizes from 16 through 256 pixels for Windows display scales and Explorer views.
