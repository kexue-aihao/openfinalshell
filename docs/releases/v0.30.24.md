## 0.30.24 更新内容

本次更新补齐 Android 运维工具，并完善桌面 RDP 平台能力与发布检查。

- Android：SSH 接入 HTTP CONNECT/SOCKS5 代理及认证；SFTP 使用系统文件/目录选择器，接入并发、覆盖策略、递归目录与打包传输。
- Android：设置中增加 AI 服务配置，SSH 页面可直接打开助手；支持 OpenAI、DeepSeek 和兼容 API、模型列表、能力声明/探测、连接延迟、流式/非流式回答、取消和手动填入终端。Token 使用 Keystore 保护，对话只保存在内存。
- Android：增加命令分组、搜索、加密导入导出与局域网传送，以及带编码选择、冲突检测和原子保存的远程文本编辑。
- 桌面：增加结构化平台能力报告，完善 RDP 文件任务取消、旧 generation 事件隔离、原生剪贴板接线及依赖打包检查。
- 构建：修复 Android 网络安全配置的 Release lint 错误、文件权限失效检测，增加 Gradle Wrapper，补齐既有界面翻译；CI 增加完整 lint 和 Release 构建检查。

### 验证范围

- Windows 本地桌面回归、真实 FreeRDP 8 项 CTest、多实例 13 个场景已通过。
- Android 70 项单元测试通过；API 26/35 x86_64 模拟器各 12 项仪器测试通过，涵盖导航、Room 迁移、Keystore、系统文件读写、续传和权限拒绝。
- 本地 Debug/未签名 Release APK/AAB 构建和 lint 通过；正式 Android 发布包由 CI 使用发布密钥签名。
- 真实 AI 服务、Android ARM64 实机及不同云文档提供器仍待验收。macOS/Linux 的文件原生粘贴、多实例和音频继续关闭，待相应平台实机验收后再开放；本次不将这些能力列为完整支持。
