# OpenFinalShell v0.30.60

- 重新调整 WinUI 3 原生工作区：监控恢复到右侧，底部通过“文件 / 命令”标签切换。
- 命令库采用紧凑的自动换行排版，右侧提供大面积命令编辑器；默认宽度约为 1:2，并支持拖动调整。
- 命令库与编辑器各自支持发送到当前或所有 SSH 会话，快捷命令旁的齿轮可编辑内容；每个会话保留独立草稿，并与终端底部快捷输入同步。
- SFTP 文件页新增左侧目录树与右侧文件表格，按需展开子目录并复用首次目录列表，支持目录选择联动和隐藏目录过滤。
- 修复底部面板留白、窄窗口发送按钮裁切，以及取消目录加载后目录树快照错位的问题。
