## 0.30.28 更新内容

修复 Android 本地终端的一处权限声明缺失，由真机实测发现。

- 修复「授予所有文件访问权限」开关无法开启：`MANAGE_EXTERNAL_STORAGE` **从未在 manifest 中声明**。没有这个声明，系统「所有文件访问权限」页面不会给应用提供可开启的开关（部分 ROM 直接置灰），`Environment.isExternalStorageManager()` 也永远返回 false —— 于是应用档的 shell 始终看不到 `/sdcard`，而这正是该档位最容易让人意外的地方。
- 该按钮此前用 `runCatching { startActivity(...) }` 把 `ActivityNotFoundException` 静默吞掉，用户点了没反应也无从得知。现在优先打开单应用设置页，失败回退到全局列表（部分 OEM ROM 只提供后者），两者都不行才报出提示。

### 验证与开放范围

- 真机（Xiaomi 23013RK75C / Android 15）与模拟器对比确认根因：修复前的已安装包中该权限出现 **0** 次，打上修复的构建为 **1** 次；模拟器上 `appops set … allow` 可正常生效，证明声明有效。
- 其余仍待真机验收的项目没有变化：**root 档（uid 0）从未在真机上运行过**（`su` 路径与 Shizuku-as-root 路径均未验证）、**PTY 的窗口尺寸是否传到内核**未验证（模拟器镜像没有 `stty`）、Android 8/9/10 的行为未实测。
