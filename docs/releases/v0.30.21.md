## 0.30.21 更新内容

- 新增 Windows 多实例窗口预览：每个窗口使用独立进程，SSH、RDP、SFTP 和 AI 请求保持运行态隔离。
- 连接、AI 配置和凭据共享；配置自动刷新，过期编辑保存时提示冲突。
- 修复 Windows 多进程安全存储密钥不一致，支持同时首次启动和重启后继续使用原凭据。
- 关闭一个实例只清理自己的会话与传输；更新由协调实例处理，等待其他进程真正退出，不强制结束无响应窗口。
- 增加 Windows 多进程自动验收和发布门禁。
- 修复 macOS 本地控制 socket 路径长度限制，以及 Android SDK 废弃包、CI 未安装 Electron 可执行文件导致的构建失败。
- 修复部分 Windows/Electron 环境拒绝透明标题栏颜色时窗口无法打开的问题，自动回退到主题实色。

### 多实例预览的使用范围

**本版本默认仍为单实例。** Windows 多实例为预览功能；真实双 RDP 会话、任务栏交互和完整安装器更新尚待实机验收。macOS/Linux 暂不开放多实例。

需要测试时，在 PowerShell 中设置预览变量后启动应用：

```powershell
$env:OFS_MULTI_INSTANCE_PREVIEW = '1'
& '实际安装路径\OpenFinalShell.exe'
& '实际安装路径\OpenFinalShell.exe' --new-instance
```

已启用预览的窗口也可通过左上角名称菜单的“打开新窗口”或 `Ctrl+Shift+N` 创建独立窗口。普通双击继续聚焦已有窗口。

验证结果：发布提交的 CI 为 1690 项测试通过、37 项按环境跳过；随后补充的标题栏启动回归测试也通过，主分支 CI 共 1691 项通过。类型、10 种语言检查和生产构建通过。真实 Windows 多进程的 11 个测试场景在本机与 GitHub Windows runner 均通过，包括关闭 A 后 B 的 16 MB SFTP 传输继续完成，以及重启后原 Vault Token 仍可用。
