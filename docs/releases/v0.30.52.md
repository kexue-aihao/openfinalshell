# OpenFinalShell v0.30.52

- WinUI 3 原生版正式发布，应用、安装器、快捷方式和迁移入口不再使用“预览版”名称。
- 命令编辑器使用独立原生窗口，支持拖动标题栏、自由调整宽高和最大化，并记住自定义尺寸。
- 恢复命令库中可见的“命令历史”标题，关闭编辑器后继续停留在命令库。

## 升级兼容性

本版本执行一次完整安装更新，以更新旧快捷方式、系统应用名称与卸载程序；后续版本继续支持签名文件增量更新。旧安装目录继续复用，新安装默认位于 `C:\Program Files\OpenFinalShell Native`。数据目录、凭据加密标识和安装注册键保持兼容，不需要重新导入连接。

原生安装包名称为 `OpenFinalShell-Native-0.30.52-<arch>-Setup.exe`。旧 Electron 版用户请先更新 Electron，或直接下载安装包；旧原生预览版可从应用内检查更新升级。

## 验证

命令编辑器已在 Windows 11 x64 隔离环境验证拖动、宽高调整、关闭重开和最大化后尺寸恢复。跨显示器 DPI 的尺寸换算由自动化测试覆盖；未进行实际跨屏验收。正式发布前执行核心契约、桌面测试、类型与国际化检查、Electron 构建及 bundle 预算检查；三架构安装包由发布流水线构建验证。
