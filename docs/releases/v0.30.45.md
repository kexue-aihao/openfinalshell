# OpenFinalShell v0.30.45

- 修复 WinUI3 原生终端中 ANSI 背景徽标、中文宽字符、emoji 和风险色带的错位与竖向接缝。
- 连续背景、选择区和搜索高亮改为合并 span 绘制，并按物理像素对齐网格边界；文本按前景色和字体样式合并为 run。
- CJK 和其他宽字符在 libvterm 报告的单元格范围内居中裁剪，不再溢出相邻单元格；字体、缩放和 DPI 变化后会重新计算终端网格。
- 继续使用系统 CJK 字体回退，不增加内置字体、配置字段或持久化格式。

## 验证

原生终端探针新增中文、emoji、组合字符、方块字符、制表符和 continuation cell 检查。完整桌面测试、原生核心契约、SSH/SFTP、TypeScript、i18n、Electron 生产构建、bundle 预算以及 WinUI3 x64/x86/ARM64 发布由本地门禁和 GitHub Actions 发版流水线验证。
