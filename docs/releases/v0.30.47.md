# OpenFinalShell v0.30.47

- 修复 WinUI3 原生终端在浅绿、粉色、黄色等明亮 ANSI 背景上默认浅灰文字对比度不足的问题。
- 仅当终端脚本未显式指定前景色时，按 WCAG 相对亮度自动选择黑字或白字，最低目标对比度为 `4.5:1`。
- 脚本显式指定的 ANSI 前景、索引色、RGB 色及反转视频前景保持原样，避免破坏远端配色语义。
- 继续保留连续背景 span、中文宽字符 run、水平和物理像素对齐逻辑。

## 验证

本地原生终端探针、388 项核心契约、SSH/SFTP 回归、桌面测试、TypeScript、i18n、Electron 构建、bundle 预算和 WinUI3 x64/x86/ARM64 构建通过；真实 WinUI3 fixture 已对照浅色 ANSI 徽标与风险条。正式安装包与发布产物由 GitHub Actions 发版流水线验证。
