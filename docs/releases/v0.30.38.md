# OpenFinalShell v0.30.38

- **调整原生预览版安装目录。** 原生 NSIS 安装器默认使用 `C:\Program Files\OpenFinalShell Native Preview`，并在安装时正确请求管理员权限；升级器同时兼容新的系统安装目录和旧版用户目录，连接和凭据仍保存在 `%LOCALAPPDATA%\OpenFinalShell.NativePreview`。

- **Use a machine-wide native preview install location.** The native NSIS installer now defaults to `C:\Program Files\OpenFinalShell Native Preview` and requests administrator permission. The updater supports both the new machine-wide location and legacy per-user installs, while connections and credentials remain under `%LOCALAPPDATA%\OpenFinalShell.NativePreview`.
