# OpenFinalShell v0.30.48

- 修复原生终端中脚本显式设置白字或浅灰字时，在浅绿、粉、黄等明亮 ANSI 背景上仍难以辨认的问题。
- 默认前景及显式黑、白、灰等中性前景会在低对比时自动选择黑白中更高者；显式饱和彩色前景保持不变。
- 从命令库点击执行命令后继续停留在命令库，不再自动切回连接工作区。
- 命令编辑器改为响应式尺寸：宽屏扩大编辑区域，竖屏保留足够书写高度，低高度窗口允许内容滚动。

## 验证

本地原生终端对比度测试、命令编辑器宽屏/竖屏/紧凑视口测试、核心契约、SSH/SFTP 回归、桌面测试、TypeScript、i18n、Electron 构建、bundle 预算和 WinUI3 x64/x86/ARM64 构建通过；真实 WinUI3 fixture 已确认显式中性前景自动提高对比度。正式安装包与发布产物由 GitHub Actions 发版流水线验证。
