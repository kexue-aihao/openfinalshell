# OpenFinalShell v0.30.37

- **修复原生 SSH 终端输入。** 修复 Windows 原生版隐藏输入框截留键盘字符的问题，普通按键、回车、快捷键和中文输入现在会正确转发到远程 shell。
- **优化 WinUI 3 原生前端。** 统一活动栏图标反馈，重排原生编辑器工具栏和状态栏，补齐标签脏状态、独立窗口主题同步以及高对比度配色。

- **Fix native SSH terminal input.** Keyboard characters were trapped in the hidden Windows native input client; regular keys, Enter, shortcuts and IME input now reach the remote shell correctly.
- **Polish the WinUI 3 native frontend.** Unify activity-rail feedback, reorganize the native editor toolbar and status bar, and add dirty tab states, independent-window theme synchronization and high-contrast colors.
