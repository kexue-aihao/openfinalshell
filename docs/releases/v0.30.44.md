# OpenFinalShell v0.30.44

- 原生命令库首次启动提供 5 个分组、26 条常用运维命令。只读诊断命令默认自动回车，安装与授权扫描命令默认等待用户审核；删除所有内置命令后不会再次自动注入。
- 新增重复命令检测、分组预览和原子清理。用户可逐组选择保留项，过期预览或不属于该组的保留项会被拒绝；命令列表同时支持右键菜单和键盘菜单。
- SSH 连接页会区分直连与跳板机流程，显示当前步骤、连接百分比以及凭据或主机密钥等待状态。关于页和状态栏改为显示 Windows 版本、完整版本号和系统架构。
- 改进浮动命令编辑器的尺寸、滚动和焦点处理，统一 Windows 10/11 的界面圆角，并在减少透明度或高对比度模式下关闭 Mica。

## 验证

本地验证结果：桌面测试 1781 项通过、37 项跳过；原生核心契约 384 项、SSH/SFTP 回归 49 项通过；TypeScript、10 种语言、Electron 生产构建、bundle 预算检查通过；WinUI3 Release x64 构建为 0 警告、0 错误。正式安装包与发布产物由本次 GitHub Actions 发版流水线验证。
