# OpenFinalShell v0.30.61

- 将 WinUI 3 原生版命令历史按钮移到终端底部快捷输入栏右侧，直接打开当前会话的历史记录。
- SSH 连接成功后自动展开命令库与命令编辑器；之后手动收起的状态在切换标签时继续保留。
- 命令库和编辑器支持勾选单个或多个 SSH 会话分发命令，并保留“当前会话”和“所有会话”快捷选项。两处目标选择相互独立，终端快捷输入仍发送到所属会话。
- 目标断开后立即更新选择数量。没有可用的选定目标时保留命令草稿，不会回退发送到其他会话。
- 顶部连接标签显示已有位置标记对应的地区旗帜，同时保留连接状态指示。重命名后仍保留旗帜，修改位置设置后已打开的标签同步更新。
