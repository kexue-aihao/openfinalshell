## 0.30.25 更新内容

本版本补齐 0.30.24 因 macOS 原生测试失败而未完成的桌面发布，并包含本轮 Android 功能移植。

- 构建修复：macOS 的系统临时目录可能经过 `/var` 符号链接，导致测试文件被安全检查拒绝。测试改用解析后的临时根目录，增加文件及父目录符号链接拒绝用例，生产文件安全限制保持不变。
- Android：SSH 支持 HTTP CONNECT/SOCKS5 代理；SFTP 接入系统文件选择、并发与覆盖策略、目录和打包传输。
- Android：增加命令库、远程文本编辑，以及设置中的 AI 配置和 SSH 页面助手；支持模型选择、连接延迟、流式/非流式回答、取消和手动填入 SSH。Token 使用 Keystore 保护，对话仅保存在内存。
- 桌面：完善平台能力报告、RDP 文件任务取消、旧会话事件隔离、原生剪贴板接线和依赖打包检查。

### 验证与开放范围

- 已有 Windows 桌面回归、FreeRDP 与多实例测试通过；Android 70 项单元测试及 API 26/35 模拟器各 12 项仪器测试通过。
- macOS/Linux 原生文件粘贴、多实例和音频仍待实机验收，正式包继续关闭这些能力；Android ARM64 实机、真实 AI 服务和不同云文档提供器仍待验收。
- Windows ARM64/x86 不新增真实 RDP Worker，Android 嵌入式 RDP 不在本次范围。

详细记录：[多端功能增量移植验收](https://github.com/kexue-aihao/openfinalshell/blob/v0.30.25/docs/platform-port-status.md)。
