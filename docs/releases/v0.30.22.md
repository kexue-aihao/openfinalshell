## 0.30.22 更新内容

- 在「设置 → 常规」增加“允许多实例窗口（预览）”开关。
- Windows 开启后可使用左上角菜单、`Ctrl+Shift+N`、任务栏“打开新窗口”和 `--new-instance`。
- 关闭开关只禁止新建实例，已打开窗口、SSH/RDP/SFTP 会话和传输继续运行。
- 开关状态会同步到其他窗口并在重启后保留；macOS/Linux 仍显示为不支持。

本版本默认关闭多实例。启用后请先确认真实 RDP 会话和更新流程符合你的使用环境。

完整说明：[多实例实现与验收](https://github.com/kexue-aihao/openfinalshell/blob/v0.30.22/docs/multi-instance.md)。
