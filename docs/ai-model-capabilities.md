# AI 模型列表与图片输入检测

设置中的“获取模型”通过用户填写的 API 地址和 Token 调用 `/models`。标准 OpenAI 兼容模型列表经常只有模型 ID、所属服务等信息，没有图片输入能力声明。“图片未声明”（旧版显示“能力未知”）表示无法从列表判断图片能力，不代表连接失败，也不阻止选择模型进行对话。

软件会解析接口明确返回的输入类型和视觉能力字段，包括 `input_modalities`、`modalities.input`、`capabilities` 和 `architecture.input_modalities`。不会根据模型名称猜测能力，也不会将图片输出能力当作图片输入能力。相互矛盾或无法识别的声明保持未确定状态。

## 检测方法

“测试连接”成功后显示本次 API 请求耗时（毫秒），从主进程发出请求计时到完整接收响应，包含网络传输和模型处理，不包含本地读取凭据或界面渲染。它使用已保存的配置；修改地址、模型或 Token 后需先保存。测试时显示加载状态，失败或切换配置后清除旧的成功耗时。

1. 打开设置中的 AI 配置，填写 API 地址和 Token，然后点击“获取模型”。
2. 从下拉列表选择模型，也可在尚未获取列表时手动填写名称。
3. 点击“测试图片输入”。测试使用当前填写的地址、Token 和所选模型，不需要先保存。若修改了地址，需要重新填写 Token，避免将旧凭据发送给其他接口。
4. 查看结果后，点击“保存配置”保存所选模型。

测试只向当前接口发送内置小 PNG 和固定测试提问，不读取用户文件或终端内容，可能产生少量 API 费用。软件不会自动执行此测试。

| 提示 | 含义 |
| --- | --- |
| 图片·接口声明 / 无图片·接口声明 | 模型列表明确声明了图片输入支持情况，尚未实测。 |
| 图片请求通过 | 接口接受了测试图片并返回正常回答；无法据此保证网关实际识别了图片，或其他图片格式同样可用。 |
| 图片输入已拒绝 | 接口明确拒绝了该模型的图片输入。 |
| 检测未能确定 | 参数、图片格式或响应格式可能不兼容，不能据此断言模型不支持图片。 |

认证失败、限流和服务端错误单独显示，并保留 HTTP 状态。错误提示不会回显接口原始响应、Token 或模型回答。测试有 30 秒超时和响应大小限制。

测试结果仅保留在当前设置面板内存中；修改地址、Token 或切换配置后失效。切换模型后到达的旧检测结果不会覆盖当前模型。浏览器调试模式不执行真实检测。

## 将回答中的命令填入 SSH

从 SSH 终端或侧栏打开 AI 助手时，当前可用的 SSH 终端会作为初始目标；也可以在回答区上方的“目标 SSH”下拉框中手动切换。回答中的 shell 代码块会显示“复制”和“填入 SSH”按钮，复制按钮可重复使用。点击填入后命令只写入终端输入行，不会发送回车或执行；确认内容无误后，再由你手动回车。多行命令只有在终端启用 bracketed paste 时才允许整段填入，否则请逐行填入。若终端已关闭、重连产生新终端或没有目标，按钮会提示终端不可用。

AI 助手还支持在“响应模式”中选择“流式”或“非流式”。流式模式会逐段显示回答；非流式模式等待接口返回完整 JSON 后一次显示。两种模式都使用同一套请求取消、响应大小限制和错误处理。

新增文案使用项目语言包；中文和英文已提供，其余语言暂使用英文占位。自动化测试使用模拟接口，真实服务的图片输入能力仍需用户主动检测和实际图片问答确认。
